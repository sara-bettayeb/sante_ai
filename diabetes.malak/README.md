# 🩺 مديول التنبؤ بمخاطر السكري (Diabetes Risk Prediction Module)

مديول مستقل للتقييم الوقائي لمخاطر مرض السكري مبني على نموذج جاهز مدرب على بيانات **BRFSS** (21 مؤشراً سلوكياً ونمط الحياة) مع واجهة تفاعلية بـ **Streamlit** وقاعدة بيانات **SQLite** لحفظ السجلات.

## 📁 هيكل المجلد
- `app.py`: الواجهة التفاعلية ومنطق التنبؤ وعرض الرسوم البيانية.
- `database.py`: إدارة قاعدة البيانات المحلية لحفظ واسترجاع نتائج الفحوصات.
- `extracted_model/model.joblib`: النموذج الجاهز المستخرج (XGBoost Pipeline).
- `requirements.txt`: المكتبات المطلوبة لتشغيل التطبيق.
- `Dockerfile`: إعداد حاوية Docker لتشغيل المديول بشكل معزول.

## 🚀 طريقة التشغيل محلياً
```bash
pip install -r requirements.txt
streamlit run app.py
